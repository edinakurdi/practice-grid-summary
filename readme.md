# CSS Grid Practice

A personal playground project dedicated to mastering CSS Grid Layout. The layout items and starter assets in this folder were generated using AI to allow for a direct focus on styling and positioning.

## 🎯 Project Goal
The objective of this project is to practice and understand core CSS Grid concepts, including:
* Grid tracks (columns and rows)
* Fractional units (`fr`) and responsive sizing
* Explicit vs. implicit grid layouts
* Grid item placement and alignment (`grid-column`, `grid-row`, `align-items`, `justify-items`)

## 🛠️ Built With
* HTML5
* CSS3 (CSS Grid)
* AI Tooling (Asset generation)
